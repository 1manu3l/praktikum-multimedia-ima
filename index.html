I. Dasar Teori Multimedia

Multimedia dalam web adalah suara, musik, video, film, dan animasi. Multimedia hadir dalam berbagai format dan bisa berupa apa saja yang bisa didengar atau dilihat. Contoh: gambar, musik, suara, video, rekaman, film, animasi, dan lain-lain. Halaman web sering mengandung elemen multimedia dari berbagai jenis dan format.

Bentuk (Format) Multimedia

Elemen multimedia (seperti audio atau video) disimpan dalam file media. Cara paling umum untuk mengenali jenis file adalah dengan melihat ekstensinya, misalnya: .swf, .wav, .mp3, .mp4, .mpg, .wmv, dan .avi.

II. Audio pada HTML5

Elemen <audio> HTML5 menentukan standar untuk menyematkan audio pada halaman web. Atribut controls menambahkan tombol play, pause, dan volume. Elemen <source> memungkinkan menentukan beberapa alternatif file audio; browser akan memakai format pertama yang dikenali.

Contoh <audio>

<audio controls>
  <source src="horse.ogg" type="audio/ogg">
  <source src="horse.mp3" type="audio/mpeg">
  Your browser does not support the audio element.
</audio>

Media Type Audio

File Format Media Type
MP3 audio/mpeg
OGG audio/ogg
WAV audio/wav

Tag HTML5 Audio

Tag Deskripsi
<audio> Mendefinisikan konten suara
<source> Mendefinisikan beberapa sumber media untuk <audio>/<video>

III. Video pada HTML5

Elemen <video> HTML5 menentukan cara standar untuk menyematkan video pada halaman web. Disarankan selalu menyertakan atribut width dan height agar halaman tidak "flicker" saat video dimuat.

Contoh <video> sederhana

<video width="320" height="240" controls>
  <source src="movie.mp4" type="video/mp4">
  <source src="movie.ogg" type="video/ogg">
  Your browser does not support the video tag.
</video>

IV. HTML YouTube Videos

Cara termudah memutar video di HTML adalah menggunakan YouTube. Langkahnya: upload video ke YouTube, catat video id-nya, lalu buat elemen <iframe> yang atribut src-nya menunjuk ke URL video tersebut.

Video YouTube Dasar

<iframe width="420" height="315"
  src="https://www.youtube.com/embed/tgbNymZ7vqY">
</iframe>

Parameter YouTube

  • Autoplay: tambahkan ?autoplay=1 pada URL agar video otomatis diputar saat halaman dibuka.
  • Loop: tambahkan ?playlist=VIDEOID&loop=1 agar video diulang terus-menerus.
  • Controls: tambahkan ?controls=0 agar tombol kontrol pemutar disembunyikan (nilai default 1 menampilkan kontrol). 
Autoplay: src="https://www.youtube.com/embed/tgbNymZ7vqY?autoplay=1"
Loop:     src="https://www.youtube.com/embed/tgbNymZ7vqY?playlist=tgbNymZ7vqY&loop=1"
Controls: src="https://www.youtube.com/embed/tgbNymZ7vqY?controls=0"

Catatan: Tag <object> dan <embed> untuk YouTube sudah deprecated sejak Januari 2015. Disarankan bermigrasi ke <iframe>.

VI. HTML Drag and Drop API

Agar sebuah elemen dapat di-drag, atribut draggable diberi nilai true. Event ondragstart menentukan data apa yang di-drag menggunakan dataTransfer.setData(). Event ondragover mengizinkan area penerima drop dengan memanggil event.preventDefault(). Event ondrop menjalankan aksi saat data dilepaskan, diambil kembali dengan dataTransfer.getData().

Contoh Drag and Drop

Seret gambar bolak-balik di antara dua kotak berikut.

function allowDrop(ev) { ev.preventDefault(); }
function drag(ev) { ev.dataTransfer.setData("text", ev.target.id); }
function drop(ev) {
  ev.preventDefault();
  var data = ev.dataTransfer.getData("text");
  ev.target.appendChild(document.getElementById(data));
}
